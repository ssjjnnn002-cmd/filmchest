# 내 아이폰에 필름함 설치하기

## 처음 한 번만

1. **Xcode에 Apple ID 추가**
   Xcode → Settings(⌘,) → Accounts → 왼쪽 아래 `+` → Apple ID → 평소 쓰는 Apple ID로 로그인
   그다음 추가된 계정을 고르고 **Manage Certificates…** → `+` → **Apple Development**
2. **아이폰 연결**
   케이블로 Mac에 연결 → 아이폰에 뜨는 "이 컴퓨터를 신뢰하겠습니까?"에서 **신뢰**
3. **아이폰 개발자 모드 켜기**
   설정 → 개인정보 보호 및 보안 → 맨 아래 **개발자 모드** 켜기 → 재시동 후 **켜기**
   (이 메뉴는 아이폰을 Xcode에 한 번 연결해야 보여요)

## 설치

터미널에서 프로젝트 폴더로 가서:

```bash
./scripts/install-iphone.sh
```

처음 실행하면 앱이 안 열릴 수 있어요. 아이폰에서
설정 → 일반 → VPN 및 기기 관리 → 개발자 앱(내 Apple ID) → **신뢰**
를 누른 뒤 다시 열면 돼요.

## 무료 Apple ID로 설치하면

- **7일마다 앱이 잠겨요.** 같은 명령을 다시 실행하면 데이터는 그대로 두고 다시 7일 쓸 수 있어요.
- 카톡·파일 앱에서 zip을 받을 때는 공유 화면 **위쪽 앱 목록의 '필름함'** 을 누르세요. 앱이 열리면서 스캔 대기 롤을 고르는 화면이 나와요.
  (아래 '동작' 목록의 '필름함으로 가져오기'는 유료 계정에서만 앱과 연결돼요)

## 유료 개발자 계정(연 129,000원)이 있으면

```bash
./scripts/install-iphone.sh --paid
```

- 7일 제한이 없어지고(1년), '필름함으로 가져오기' 동작이 바로 앱을 열어요.
- TestFlight로 친구들에게 설치 링크를 보낼 수도 있어요.

## 안 될 때

| 메시지 | 해결 |
| --- | --- |
| 개발 인증서를 찾지 못했어요 | 위 1번의 Manage Certificates에서 Apple Development 인증서를 만들어 주세요 |
| 연결된 아이폰을 찾지 못했어요 | 케이블 연결, 신뢰, 개발자 모드를 확인해 주세요 |
| `Failed to register bundle identifier` | 번들 이름이 겹친 경우예요. `BUNDLE_ID_PREFIX=kr.내이름.filmchest ./scripts/install-iphone.sh` 처럼 바꿔서 실행 |
| 무료 계정 앱 개수 제한 | 무료 계정은 동시에 3개 앱까지만 설치돼요. 예전에 설치한 개발 앱을 지워 주세요 |
