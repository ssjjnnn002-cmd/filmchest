## 2. 앱 안 '함께 만든 분들' (텀블벅 선물 아이템 1)

- 설정 맨 아래(버전 줄 근처)에 **함께 만든 분들** 줄 → 후원자 이름 목록 화면.
- 이름은 세 앱이 같은 목록을 쓰게 한 파일로 둔다 (예: `web/src/core/supporters.ts` → 갤럭시 동기화, 아이폰은 같은 내용의 Swift 배열 또는 JSON 리소스).
- 펀딩이 끝나기 전에는 목록이 비어 있다. 비어 있으면 줄을 숨긴다.
- 이름은 결제 끝난 뒤 텀블벅 후원자 관리에서 '올릴 이름' 답을 받아 넣는다 (빈 칸은 올리지 않음). 4월 정식 출시 버전에 들어가야 함.
- 선물 이미지(`marketing/tumblbug/gift-1.png`)와 모양을 크게 다르지 않게: 제목 '고마운 후원자', 이름 한 줄씩.

## 3. 프리미엄 구조 (결제 없이 틀만, 기본은 꺼 둠)

기획안 3·4번의 무료/프리미엄 구분. **펀딩이 끝날 때까지 유료 판매를 시작하면 안 되므로**, 지금은 `features`에 스위치를 두고 꺼 둔 채 만든다.

| | 무료 | 프리미엄 |
|---|---|---|
| 롤 | 달마다 4롤 장착 | 무제한 |
| 기본 기록 | O | O |
| 컷별 상세 기록 | — | O |
| 노출계 | — | O (노출계 자체는 꺼진 상태 유지) |
| 해지 후 기록 | 유지 | 유지 |

- `web/src/core/features.ts`에 `premium: false` 스위치. 꺼져 있으면 지금과 똑같이 모두 쓸 수 있어야 한다.
- 프리미엄 여부는 한 곳(예: `isPremium()`)에서만 판단하게 하고, 나중에 스토어 결제(StoreKit 2 / Google Play Billing)와 텀블벅 코드로 채운다. 지금은 개발용으로 켜고 끌 수 있게만.
- 무료 4롤 제한: 그 달(기기 시간 기준 1일~말일)에 장착한 롤 수로 센다. 넘으면 장착 화면에서 안내(막기 전에 문구는 창작자에게 확인).
- '컷별 상세 기록'이 앱의 어느 화면·칸인지 창작자에게 먼저 확인하고 잠근다.
- 잠겨도 이미 남긴 기록은 보이고 지워지지 않아야 한다.

## 진행 기록 (2026-11-25 클라우드 세션)

- 0번: 클라우드 세션엔 Chrome이 연결돼 있지 않아 확인 못 함. 창작자 컴퓨터에서 확인 필요.
- 1번: 실제 기기 확인·APK 빌드는 못 함(안드로이드 SDK 없음). 아이폰 `LoadFilmView`: 장착 처리를 동기로 바꾸고 장착에 성공하면 화면이 닫힐 때까지 `loading`을 풀지 않음. 앱 시작 때 `Trash.removeDoubleLoads` (같은 카메라·필름 1분 안, 사진·컷 기록 없는 중복 롤 → 삭제한 롤로; 아이폰은 두 번째 장착이 첫 롤을 '촬영 완료'로 바꾸므로 그것도 봄). Xcode 빌드 확인 필요.
- 2번: `web/src/core/supporters.ts` 한 파일 → 동기화 스크립트가 갤럭시 `galaxy/src/core/supporters.ts`, 아이폰 `App/Shared/Model/Supporters.swift`를 만든다. 설정 › 정보에 '함께 만든 분들'(비어 있으면 숨김) → '고마운 후원자' 목록.
- 3번: `features.premium = false` (아이폰 `Features.premium`). 판단은 `web/src/core/premium.ts`의 `isPremium()` / 아이폰 `Premium.isPremium` 한 곳. 무료 월 4롤(장착 때 센 수와 이번 달 장착한 롤 중 큰 쪽, 가져온 롤 제외), 잠그는 건 다이얼 '상세 기록' 화면만(창작자 확인: 장소·렌즈·촬영일·컷별 촬영 정보 고치기는 그대로). 문구는 날짜 포함 안. 개발자 모드(웹·아이폰)에 '무료/프리미엄 구분 시험'·'프리미엄 이용 중 (시험)'. 갤럭시엔 개발자 모드 화면이 없어 시험 줄 없음.
- 아이폰에 예전 계획(12롤 뒤 월 2,500원 구독)의 StoreKit 코드가 꺼진 채 남아 있음(`Subscriptions`, `PaywallView`). 결제 붙일 때 연 9,900원 계획에 맞게 `Premium.isPremium`으로 옮길 것.
