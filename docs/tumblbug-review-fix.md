# 텀블벅 심사 보완 (2026-11-24 보완 요청 대응)

심사팀이 요청한 3가지를 어디에 무엇을 넣는지 순서대로 정리했다. 텀블벅 편집 화면에서 아래 순서대로 붙여 넣고 **심사 요청**을 다시 누른다.

---

## 1. 생성형 AI 사용 표시

### 1-1. [프로젝트 계획] 맨 첫 줄: AI 사용 안내 이미지

- 보완 요청 메일의 **"안내 배너 다운로드 바로가기"**에서 받은 이미지를 프로젝트 계획 **맨 첫 줄**에 넣는다.
- 이미지와 위치는 고치면 안 된다 (텀블벅 규정).

### 1-2. [신뢰와 안전] → 프로젝트 정책 맨 첫 줄

기존 정책 문구 **위에** 그대로 붙여 넣는다.

```
※ 본 프로젝트는 생성형 AI를 활용하여 제작된 콘텐츠를 포함합니다.
사용 프로그램 정보: Claude(Anthropic, Claude Code), Cursor
사용 범위: 앱(아이폰·갤럭시·웹) 프로그램 코드 작성, 상세페이지와 선물 설명 글 초안, 대표 이미지·선물 안내 이미지·소개 영상의 편집과 배치
사용 방식: 앱의 기능과 방향은 창작자가 정하고, AI 도구에 요청해 코드와 화면을 만들고, 창작자가 직접 써 보며 확인하고 수정을 요청합니다. 상세페이지와 선물 설명 글은 AI가 쓴 초안을 창작자가 확인해 정합니다. 대표 이미지·선물 안내 이미지·소개 영상은 실제 앱 화면과 글자·도형을 AI가 작성한 코드로 배치해 만들었으며, 이미지 생성 AI로 그린 그림이나 사진은 없습니다.
```

## 2. [신뢰와 안전] → 인증서류: 앱 사전 확인서

- 파일: `marketing/tumblbug/app-precheck.docx` (작성 완료, 7개 질문 모두 답변)
- **서명란**에 이름·날짜를 적고 PDF로 저장해 [인증서류 제출]에 올린다.
- 3번 질문(체험 가능한 시제품): 확인서에 "체험 영상은 프로젝트 대표 영상으로 올렸습니다"라고 적혀 있다. 대표 영상(`marketing/tumblbug/filmchest-video.mp4`)이 실제로 올라가 있는지 확인한다.
- 일정은 월 단위로 적혀 있다 (2026.12 심사 → 2027.1 펀딩 → 2027.2 베타 → 2027.3 노출계·액자 저장·스토어 심사 → 2027.4 정식 출시).

## 3. [프로젝트 계획] 선물 품목 이미지와 설명

프로젝트 계획에 **"선물 안내"** 칸(소제목)을 만들고, 아이템마다 이미지 1장 + 설명을 넣는다.
이미지: `marketing/tumblbug/gift-1.png` ~ `gift-4.png` (1200×1200)

**배송 없는 디지털 선물이에요.** 모든 선물은 텀블벅 '디지털 선물'과 메시지로 전달해요.

### 사용권 안내 (아이템 3·4 공통)

- 코드는 다른 사람에게 줄 수 있어요(양도 가능). 한 코드는 한 계정에서 한 번만 쓸 수 있어요.
- 코드 등록 기한: 받은 날부터 3개월
- 현금이나 다른 상품으로 바꿀 수 없어요.
- 코드가 안 되면 텀블벅 메시지로 알려 주세요. 새 코드를 다시 보내 드려요.
- 코드 모양은 이미지와 다를 수 있어요 (스토어가 만든 코드 형식을 따라요).
